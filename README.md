# market-brief

AI-generated daily briefing of the Brazilian market: collects economic indicators and headlines,
writes a short summary with Claude, sends it via Telegram and publishes it on GitHub Pages.

> 🚧 Work in progress. A full README with architecture, screenshots and setup is coming.
